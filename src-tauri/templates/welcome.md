# 欢迎使用青简

青简是一个**完全本地**的 Markdown 编辑器：笔记以 `.md` 文件保存在你选择的文件夹里，数据库只记录元数据与搜索索引，随时可以用别的编辑器打开这些文件。

## 元数据

文件最上方的 `---` 区块是 YAML 元数据，用来记录标题、作者、标签之类。正文上方会显示一条提示，点「编辑」即可修改；里面的 `title` 会优先作为笔记名。

## 开始写作

在左侧「文件」面板里点选一篇笔记，或按 `Ctrl + N` 新建。编辑内容会自动保存，也可以按 `Ctrl + S` 立即保存。

输入 `/` 可以唤起插入菜单；选中文字会出现格式浮层。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `Ctrl + S` |
| 加粗 / 斜体 | `Ctrl + B` / `Ctrl + I` |
| 标题 1–6 级 | `Ctrl + 1` … `Ctrl + 6` |
| 恢复普通段落 | `Ctrl + 0` |
| 代码块 | `Ctrl + Shift + K` |
| 引用 | `Ctrl + Shift + Q` |
| 无序 / 有序列表 | `Ctrl + Shift + ]` / `Ctrl + Shift + [` |
| 表格 | `Ctrl + T` |
| 插入链接 | `Ctrl + K` |
| 偏好设置 | `Ctrl + ,` |

完整的 Typora 键位对照在「设置 → 快捷键」里。

## 代码

行内代码写成 `let x = 1;`，代码块带语法高亮：

```rust
fn main() {
    let notes = vec!["青简", "Markdown"];
    for note in &notes {
        println!("{}", note);
    }
}
```

## 列表

- 支持**无序列表**，可以嵌套
  - 第二层缩进用 `Tab`
  - 反缩进用 `Shift + Tab`
- 搜索支持中文子串，例如搜「借」能命中「借用检查」

1. 有序列表按 `Ctrl + Shift + [`
2. 回车自动续号
3. 空项回车退出列表
